# 일일 백업

`.github/workflows/daily-backup.yml`이 매일 밤 8시(KST)에 이 폴더로 두 벌을 커밋합니다.

| 파일 | 용도 |
|------|------|
| `vouchers_YYYY-MM-DD.json` | **복구용 정본.** 그날 저녁 8시 시점의 `vouchers` 테이블 전체 스냅샷(레코드 배열, 각 항목에 `id` 포함). |
| `vouchers_YYYY-MM-DD.xlsx` | **비상용 사본.** 같은 데이터를 원래 대장 양식(EO_FB / EO_RM / HR 시트)으로 정리한 것. 앱을 못 쓰게 되더라도 사람이 바로 열어볼 수 있게 하려는 것. |

최근 **14일치**만 보관하고 그 이전 파일은 자동으로 정리됩니다. (git 히스토리에는 예전 파일도
그대로 남으므로, 필요하면 저장소 커밋 기록에서 더 오래된 것도 꺼낼 수 있습니다.)

## 복구가 필요할 때

앱 사이드바 → **가져오기/내보내기** → **백업에서 복원**에서 원하는 날짜의 **`.json`** 파일을
올리면 됩니다. `id` 기준으로 덮어쓰기(upsert)만 하므로 몇 번을 다시 올려도 중복이 생기지
않습니다 — 2026-08-25 사고를 냈던 "엑셀 가져오기"(매번 새 레코드 생성)와는 근본적으로 다른
방식입니다.

⚠️ **`.xlsx` 파일은 앱으로 다시 가져오지 마세요.** 엑셀 가져오기는 새 `id`를 발급해서 전부
중복 등록됩니다. 이 파일은 어디까지나 눈으로 확인하고 보관하는 사본입니다.

## 지금 당장 백업이 필요하면

GitHub 저장소 → Actions → **Daily voucher backup** → **Run workflow**로 예약 시간과
무관하게 즉시 실행할 수 있습니다.
