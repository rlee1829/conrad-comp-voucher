# 일일 백업

`.github/workflows/daily-backup.yml`이 매일 밤 8시(KST)에 자동으로 이 폴더에
`vouchers_YYYY-MM-DD.json`을 커밋합니다. 최근 30일치만 보관되고 그 이전 파일은
자동으로 정리됩니다.

각 파일은 그날 저녁 8시 시점의 `vouchers` 테이블 전체 스냅샷(레코드 배열, 각 항목에
`id` 포함)입니다.

## 복구가 필요할 때

앱 사이드바 → **가져오기/내보내기** → **백업에서 복원**에서 원하는 날짜의 파일을
올리면 됩니다. `id` 기준으로 덮어쓰기(upsert)만 하므로 몇 번을 다시 올려도 중복이
생기지 않습니다 — 2026-08-25 사고를 냈던 "엑셀 가져오기"(매번 새 레코드 생성)와는
근본적으로 다른 방식입니다.

## 지금 당장 백업이 필요하면

GitHub 저장소 → Actions → **Daily voucher backup** → **Run workflow**로 예약 시간과
무관하게 즉시 실행할 수 있습니다.
