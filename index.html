승인대기로 등록됩니다. Mate 승인번호를 이미 받았다면 함께 적어 올리세요 — 승인자가 확인 후 승인합니다. 아직 못 받았다면 비워두고 요청해도 되고, 번호가 나온 뒤 [수정]으로 채워 넣으면 승인됩니다.

발행 가능 종류

증서번호 중복, Mate 승인번호 누락(활성 상태), 만료일이 발행일보다 빠른 경우, 만료됐는데 아직 활성 상태인 건, 가져오기 시 사유 카테고리를 자동추정한 건을 자동으로 점검합니다. 증서번호를 클릭하면 상세 정보로 이동합니다. 사유 카테고리 항목은 확인 후 [확인]을 누르면 목록에서 사라집니다.

정합성 점검

전체 바우처에 걸쳐 발생한 발행·승인·반려·사용·연장·취소·수정·되돌리기 작업을 시간순으로 모아봅니다. 증서번호를 클릭하면 상세 정보로 이동합니다.

엑셀 내보내기

현재 목록 화면에 적용된 필터 기준으로 내보냅니다.

원본 형식으로 전체 내보내기

필터와 무관하게 전체 데이터를, 원래 대장 엑셀과 같은 열 구성으로 EO_FB·EO_RM·HR 시트로 나눠 내보냅니다. 대조·백업용입니다 — 다시 가져오면 새 레코드로 중복 등록되니 복원 용도로 쓰지 마세요.

백업에서 복원

매일 저녁 8시 자동 저장되는 백업(.json)에서 복원합니다. id가 같으면 덮어쓰고, 없으면 추가합니다 — 몇 번을 다시 올려도 중복이 생기지 않습니다.
기존 엑셀 대장(F&B/Room 통합 대장의 EO_FB·EO_RM 시트, 또는 HR Voucher Tracking Sheet)을 업로드해 일괄 등록합니다. 상태값이 불명확하거나 발행일 정보가 없는 행은 자동으로 추정 처리되며, 목록의 비고란에 "[가져오기 검토 필요]" 표시가 남습니다.

엑셀 가져오기

2026-08-25 재삽입 사고로 이 기능은 잠겨 있습니다. 파일 선택·가져오기 버튼 모두 비활성화되어 있으며, 코드를 직접 수정해야 다시 켤 수 있습니다.
담당자 이름이 승인자·관리자 명단에 있으면 자동으로 해당 모드가 적용됩니다. 사이드바 "모드"에서 직접 바꿀 수도 있지만, 명단에 없는 모드 버튼은 애초에 보이지 않습니다. 바우처 목록은 발행이 완료된 건(ACTIVE·USED·EXPIRED·VOID)만 보여줍니다 — 승인대기 중인 건은 승인 대기함에서 확인하세요.

요청자 모드

기본 모드
  1. ＋ 새 발행 → 신청서 작성
    타입(F&B/Room/HR) → 바우처 종류 → 사유 카테고리 → 발행일/만료일 → 세부 목적을 입력합니다. Mate 승인번호는 이미 받은 경우에만 적으면 됩니다.
  2. [발행 요청] 클릭
    요청자 모드에는 GM 승인 체크박스가 없어 승인대기 상태로 등록되고, 화면이 자동으로 승인 대기함으로 이동합니다.
  3. ✓ 승인 대기함에서 진행 확인
    승인 전에는 바우처 목록에 나타나지 않고 승인 대기함에만 보입니다. 승인되면 상태가 ACTIVE로 바뀌면서 바우처 목록에도 나타납니다. 목적·번호를 고쳐야 하면 [수정]으로 보완할 수 있습니다.
  4. 반려됐다면
    반려된 건은 승인 대기함·바우처 목록 어디에도 남지 않습니다 — 반려 사유는 사이드바 감사 로그에서 증서번호나 담당자 이름으로 검색해 확인할 수 있습니다.

승인자 모드

승인자 명단
  1. ✓ 승인 대기함에서 검토
    각 건에서 [승인] 또는 [반려]를 누르거나, 여러 건을 선택해 상단에 뜨는 버튼으로 한 번에 처리할 수 있습니다.
  2. 승인 = Mate 승인번호 확인
    요청자가 미리 적어둔 번호가 있으면 자동으로 채워집니다 — 맞으면 그대로, 다르면 정확한 번호로 고쳐서 승인합니다. 번호가 없으면 승인할 수 없고 대기함에 남겨둡니다.
  3. 반려 = 사유 필수
    사유를 입력해 [반려 처리]를 누르면 곧바로 요청자에게 보낼 반려 알림 메일 작성 화면이 열립니다(주소 입력 후 [메일 열기] → 보내기는 직접 클릭). 입력한 사유는 감사 로그와 해당 건 상세에도 기록됩니다.
  4. 연장
    ACTIVE 또는 EXPIRED 상태인 바우처의 [연장] → 새 Mate 승인번호를 입력합니다.
  5. 🖨 픽업 대기함 관리
    실물 인쇄 후 [인쇄완료]를 누르면 곧바로 픽업 알림 메일 작성 화면이 이어서 열립니다(요청자 이메일 앞으로 채워짐, 전송은 직접 클릭). 나중에 다시 보내려면 목록 일괄바의 [픽업 알림]을 따로 눌러도 됩니다. 전달 후 [픽업완료]로 마무리합니다.
발행도 직접 할 수 있습니다 — 새 발행 화면에서 GM 승인 완료를 체크하면 승인 절차 없이 바로 ACTIVE 상태로 발행됩니다(Mate 번호 필수).

관리자 모드

관리자 명단
  1. 승인자 기능 전부 포함
    승인/반려·연장·픽업 관리(인쇄완료·픽업 알림·픽업완료)를 관리자 모드에서도 그대로 사용합니다.
  2. 사용 처리
    ACTIVE 또는 EXPIRED 상태인 바우처를 사용 처리합니다. 사용일이 만료일보다 늦으면 먼저 연장부터 해야 합니다.
  3. 발행 취소 / 삭제
    발행 취소를 누르면 상태가 VOID로 바뀌고 기록은 남습니다. 삭제는 완전히 제거되어 기록도 사라집니다. 둘 다 사유 입력이 필수이며, 처리 직후 [되돌리기]로 복구할 수 있습니다.
  4. 승인자·관리자 명단 관리
    사이드바 "승인자 명단 관리…" / "관리자 명단 관리…"에서 담당자 등록 이름을 그대로 추가·삭제합니다.
  5. ⇅ 내보내기·백업, ⚠ 정합성 점검
    엑셀 가져오기는 2026-08-25 사고 이후 잠겨 있습니다. 대신 원본 형식 전체 내보내기(대조·백업용)와, 매일 밤 자동 저장되는 백업에서 복원(id 기준으로 덮어쓰므로 몇 번을 다시 해도 안전)을 씁니다. 정합성 점검에서는 증서번호 중복·Mate 번호 누락·날짜 오류·사유 카테고리 미확인 건을 확인할 수 있습니다. 전부 관리자 전용입니다.
관리자 명단이 비어 있으면 아직 아무도 지정되지 않은 것이라 임시로 전원이 관리자로 동작합니다. 1명이라도 등록되는 순간부터 명단 소속자만 관리자가 됩니다.
